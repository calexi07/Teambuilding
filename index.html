🔴 Mod Local - Firebase neconfigurat

📋 Pentru sincronizare în timp real:

  2. Creează un nou proiect
  3. Activează "Realtime Database"
  4. În regulile database-ului, pune: 
    {
  "rules": {
    ".read": true,
    ".write": true
  }
}
  5. Copiază configurația din Project Settings
  6. Înlocuiește-o în codul HTML (vezi comentariul din cod)
